# Trial #003

The exercise is to reproduce the behavior of three functions from a protected sample. An analyst gets a way to query the sample and submits an implementation that can be checked against inputs that were held back during the exercise.

We’ll judge a reconstruction by whether it returns the expected outputs for those held-back inputs. Any write-up should include the build tested, which functions were reconstructed, the time spent, and enough detail for someone else to understand the result. Where the time or conditions are unknown, we’ll say so.

## Status

This page describes the evaluation plan. The public repository currently contains the brief. Results from this exercise will apply to the sample and the conditions tested.
